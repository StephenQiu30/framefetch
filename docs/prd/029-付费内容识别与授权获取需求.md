# 付费内容识别与授权获取需求

## 目标与范围

识别已知 B 站充电、抖音付费与试看信号，避免用户得到残缺视频或反复被要求登录。
本期不承诺下载付费完整版；不支持无权益访问、消费者 VIP 解密、共享 Cookie、第三方解析服务。

## 用户行为

- 公开普通内容：原解析、选格式、创建任务流程不变。
- 已知付费/充电：结果页说明限制，不出现可用下载格式或下载按钮。
- 已知试看：明确不代表完整内容，不显示猜测的原片时长。
- 已购买标记：说明尚无可验证导出授权，不承诺登录即可下载。
- 权益字段异常：停止并给出可理解的原因，不重试其他提取方式绕过判断。
- 排队后访问状态变化：执行前复核，失败按内容限制呈现，不产生成功制品。

## 非功能需求

不改变现有 API 必需字段和数据库结构；不记录原始账号数据；可通过平台脱敏夹具回归。
腾讯视频维持既有官方播放提示。Flutter 客户端可继续读取现有 user_action；本期仅扩展 Next.js 具体原因标题，不改变跨端契约。

## 后续放行条件

明确用户需求规模、官方导出渠道、逐资产授权、真实非 DRM 样本、完整性验证和维护责任后，才评估付费下载生产功能；目前没有这些证据，不能用开源项目 README 代替验收。
