# 032 腾讯视频与优酷个人下载需求

个人部署者使用自己的有效平台会话，尝试下载账号可访问的完整非 DRM 单视频到本地观看。正常容器重启不重复配置；新机器通过私有迁移恢复状态。

验收要求：两个平台独立启用；缺失会话、无效响应、试看、DRM 分别反馈；只有实际完整文件验证通过才生成制品；不声称未验证平台可用。不接受普通 API 上传 Cookie，不做全集抓取、共享会员、权益扩大或自动续期。

完整 VIP 成功需要至少各一个用户样本，在持有会话的部署环境中下载、ffprobe、人工首中尾播放，并在容器重建后重复验证。
