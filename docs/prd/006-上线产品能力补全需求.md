## 当前交付范围

- 保留独立 Next.js 前端和 FastAPI 后端，业务路由、配置和文档一致。
- 本机启动与验证复用已有基础服务和环境配置，不另建基础环境或重复初始化。
- 已登录高成本入口按账户限流；匿名认证入口按邮箱摘要和真实客户端地址限流。导入、下载、首次分析及分析重试共同受账户事务配额约束。
- 配额在并发、多 API 进程和资源重放时成立；删除不能重置每日预算，查询、取消、删除始终保留恢复路径。
- 控制账户活跃数、每日任务/字节、长期制品存储和首次/重试分析工作量；管理员可按用户豁免或覆盖，空值使用系统默认。
- 管理员账号免受账户级资源配额和业务操作限流约束，但仍受单文件/执行安全边界及 Provider 权限判断约束；管理员身份必须来自认证会话角色。
- RabbitMQ 与有界 Worker 池控制全局执行容量，合法任务在繁忙时保持排队，不由 API 全局计数拒绝。
- 配额失败返回可识别的 429 和 `Retry-After`，Web 显示中文恢复建议。
- 创建或重试任务后使用客户端路由；后台认证恢复不清空已登录页面，并发 Refresh 不得清除已经轮换的新 Cookie。
- 每个容器只接收职责所需配置和密钥。代理信任允许环境覆盖，同时与 Next.js 实际地址一致。
- PostgreSQL 当前态 SQL、ORM、测试同步；前端仍消费生成的 OpenAPI 客户端。

## 公网上线条件

公开上线必须同时完成目标环境的 TLS/代理链、网络隔离、真实授权媒体和 AI 端到端验证、容量测试、备份恢复、告警、隐私与支持流程。开放注册还需邮箱验证、密码恢复和整账户注销能力；目前自托管账号基线不等于完整公共 ToC 账户生命周期。

这些条件分别记录证据，缺失时保持 Pending。仓库测试不能替代生产环境证据。音频、字幕、批量、商业计费和团队协作不属于本次审核缺陷修复范围，不为它们预建抽象或接口。
