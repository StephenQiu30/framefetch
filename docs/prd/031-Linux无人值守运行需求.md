# 031 个人部署重启与换机需求

- 状态：文件来源已实现，目标环境验收待完成。
- Design：[设计](../design/031-Linux无人值守运行设计.md)。

1. 个人使用，以容器重启和换机时无需改代码、重新适配为目标，不建设企业凭据管理平台。
2. 有效会话与配置独立于容器临时目录；普通重启自动读取原配置。首次授权或迁移个人状态是一次性部署工作。
3. 新机器支持文件来源，不强制依赖 macOS Chrome；动态浏览器专属能力准确标注。
4. 仅启动已配置的受控平台；其他平台会话缺失不阻塞核心服务。
5. 会话文件替换、失效、格式错误有明确失败；不把新的账号悄悄绑定到旧任务。
6. 不把本地恢复测试等同于所有平台真实下载通过。平台协议变化通过版本更新处理，平台要求重新授权时只处理该授权。
