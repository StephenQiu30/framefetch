# 031 Linux 无人值守运行需求

- 状态：目标已确认，功能待实现。
- Design：[Linux 无人值守运行](../design/031-Linux无人值守运行设计.md)。

1. 目标环境为 Linux 服务器，无需桌面登录；首次部署和首次授权完成后，普通重启不要求人工适配、打开浏览器或重新授权。
2. 前提为授权有效、上游协议未变且持久存储可用。授权到期、撤销、网络中断和解析器回归须可区分，给出准确恢复动作。
3. 原有任务重启后可查询并自动收敛；重复消息和旧执行者不得产生重复计费或重复逻辑制品。恢复可以重新执行，不承诺所有平台支持断点续传。
4. 各平台独立报告可用性。未经 Linux 实测的平台不得显示为已通过无人值守验收，也不得影响其他平台与文件导入、分析功能。
5. 支持平台允许的自动续期；平台要求人工重新验证时，只提示受影响授权，不将全系统重启或改代码作为处理方式。
6. 平台适配器按版本发布、验证和回滚，普通启动不升级依赖。
7. 本期先满足单机重启恢复。高并发与跨主机 HA 另以测量和故障演练验收，不以容器数量作为达标依据。
