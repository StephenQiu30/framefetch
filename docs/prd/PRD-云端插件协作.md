# 云端插件协作

## 用户任务与范围

用户在日常 Chrome 中保持平台登录，Framefetch 扩展直接连接自己部署的云端服务；在 Web 提交 X、YouTube 链接后，云端 Runner 按需取得当前身份并解析、下载。用户已选择插件直连云端 WSS，不以本机身份服务或身份 SSH 隧道作为使用前提。

本需求完善现有插件身份链路，并修复已声明却缺少实现的 X L3 浏览器回退。内容范围沿用[产品边界](../design/01-产品定位与边界.md)与[解析引擎](../design/14-解析引擎.md)，连接设计见[云端插件连接](../design/17-云端插件连接.md)。实现与线上验证状态见[执行计划](../plan/PLAN-云端插件协作.md)，业务服务健康不能代替插件、平台与完整文件验收。

## 功能要求

| 编号 | 要求 | 验收条件 |
| --- | --- | --- |
| FR-01 | 插件支持经显式配置的 HTTPS 服务对应的 WSS 连接 | 普通 Chrome 中的插件通过有效 TLS 与双向配对认证连接目标云端；断网后自动重连 |
| FR-02 | 保留现有本地使用方式 | 未选择云端时仍连接本机；同一插件实例只有一个明确的服务目标，不同时向多个服务发放身份 |
| FR-03 | 身份按任务获取 | 云端 Runner 经私有认证入口取得实时身份；无材料、断连、超时与账号变化沿用现有结构化失败 |
| FR-04 | 插件状态与目标可见 | 显示当前连接的服务与连接状态；不把连接成功或材料可读显示为解析／下载成功，不展示秘密 |
| FR-05 | X L3 正式回退 | 使用 X 页面自身发出的第一方响应匹配目标推文及视频；不再返回 browser_parser_missing；拒绝私密、付费、保护或无法证明范围的内容 |
| FR-06 | 线上协作验证 | 原失败任务或用户可访问的公开样本经正式 API 重新解析；记录实际 identity_used、层级与失败分类；完整文件需独立校验 |

## 非功能约束

- 使用现有配对密钥双向挑战应答；服务地址不携带密钥、账号或令牌，不通过 URL 查询串认证。
- Cookie 与平台认证材料不进入业务 API、数据库、队列、Temporal、日志或持久材料库；Runner 仅使用操作私有 tmpfs。
- 配对密钥保存在扩展私有生成配置与云端宿主的私有身份配置，仍不进入业务容器。Runner Bearer 与配对密钥保持独立。
- 仅开放扩展 WSS 入口；Cookie、状态与回执 HTTP 接口不对公网开放。扩展权限限定显式目标，不申请通用网页代理权限。
- 云端海外出口是独立前提；WSS 不转发 X、YouTube 的普通网页或视频流量。不购买或臆造代理节点，不复制宿主 CLI 登录目录。

## 验收边界

协议、解析器夹具与本地浏览器测试分别记录；它们不替代真实云端任务或完整文件证据。平台登录由用户在普通 Chrome 中完成，不自动填写账号、密码、验证码或二次认证。
