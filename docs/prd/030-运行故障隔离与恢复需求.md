# 030 运行故障隔离与恢复需求

- 状态：Accepted for implementation
- Design：[运行故障隔离与恢复](../design/030-运行故障隔离与恢复设计.md)

1. 单个或全部媒体 Runner 暂不可用时，核心 API 仍可提供查询和其他可用能力；操作失败保留准确稳定错误。
2. 宿主会话代理仅安装但不能响应时，不得显示受控 Runner 就绪；健康检查不能读取用户会话。
3. 正常停止给下载 Worker 留出实际排空时间；异常丢失的执行仍能按已有租约机制收敛。
4. 不以本轮代码和模拟测试宣称第三方平台已经全部恢复，也不更改现有内容授权边界。
