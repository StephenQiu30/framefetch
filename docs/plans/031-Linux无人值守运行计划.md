# 031 个人部署重启与换机计划

- 状态：文件来源与生产拓扑已实现；等待目标平台验证。
- Design：[设计](../design/031-Linux无人值守运行设计.md)
- PRD：[需求](../prd/031-Linux无人值守运行需求.md)
- Acceptance：[验收](../acceptance/031-Linux无人值守运行验收.md)

1. 接入只读 Cookie 文件来源，复用现有 ProviderSessionStore、域名与会话策略、tmpfs 操作目录。
2. 增加重建、路径迁移、文件替换、到期、跨平台与危险文件类型回归测试。
3. 生产八个普通 Cookie 平台使用独立文件挂载；视频号继续可选浏览器路径。受控 profile 和路由由个人配置保存。
4. 验证后端、生产 Compose 解析和 Linux 非 root 运行，补充首次配置、重启、迁移手册。
5. 使用用户选择的平台与有权处理的测试内容，验证同链接重启前后实际交付；未提供真实会话与样本前，保持该验收待完成。

本轮不自动导出个人浏览器会话、不修改现有环境文件、不重启已有业务容器、不推送远端。Linux 文件模式不依赖实际工作机安装的 macOS 代理。
