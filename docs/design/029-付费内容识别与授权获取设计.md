# 付费内容识别与授权获取设计

## 决策

本期交付 B 站充电、抖音付费及试看信号识别与下载阻断，不交付通用 VIP 解析器。
优先解决「试看被当成完整视频」及不准确的登录提示。普通公开媒体保持原有链路。
消费者已购买标记只说明观看权益，不构成本产品可验证的文件导出授权。
腾讯消费站继续沿用 024 的官方播放边界；不新增会话池、第三方解析站或 DRM 解密。

## GitHub 核查依据（2026-09-07）

- [固定版 yt-dlp Bilibili 提取器](https://github.com/yt-dlp/yt-dlp/blob/3a08beaf031ab68f966401ead017ac81fe8486cf/yt_dlp/extractor/bilibili.py)：普通 BiliBiliIE 在原始 videoData 中读取 is_upower_exclusive；有格式时，试看可能仅产生 warning，最终格式不携带完整权益字段。因此必须在归一化之前识别，而非只检查输出 availability。
- [bilibili-charging-downloader](https://github.com/montrush/bilibili-charging-downloader) 宣称依赖已充电账号；[issue 1](https://github.com/montrush/bilibili-charging-downloader/issues/1) 反馈仅有免费试看。项目宣称不等于当前版本实测，不能直接作为生产承诺。
- [douyin-downloader paid_content.py](https://github.com/jiji262/douyin-downloader/blob/main/utils/paid_content.py) 使用 charge_info、has_paid、preview_config 区分付费与试看；[issue 188](https://github.com/jiji262/douyin-downloader/issues/188) 存在购买后仍黑屏/试看的反馈。因此登录、成功退出、产生 MP4 均不足以证明完整可用。

除固定版 yt-dlp 外，上述默认分支会变化；仅用于字段和风险调研，不引入代码依赖，未复制第三方下载实现。没有真实账号或购买样本，未宣称授权内容端到端通过。

## 本期链路

原始平台 JSON → 独立 yt-dlp 插件检查 → 稳定内部原因码 → 非可下载 inspection → 原有解析结果 UI。
下载执行沿用既有重新 inspect 门禁，限制原因归入 provider_content_restricted，不因排队前曾成功而继续下载。

成功提取后的非致命解析警告不应覆盖有效公开媒体：媒体存在性检查同时识别 image_gallery 的非空 assets URL；随后仍逐项执行图文元数据与地址校验。付费和试看原因优先阻断，不因存在 assets 而被忽略。

| 原始证据 | restriction_reason | 用户呈现 |
| --- | --- | --- |
| B 站 is_upower_exclusive | content_supporter_only | 充电专属，暂不直接下载 |
| B 站 accept_description 含试看 / is_preview | content_preview_only | 不能作为完整视频交付 |
| 抖音 charge_info.is_charge_content | content_paid_only | 付费内容，暂不直接下载 |
| 上项且 has_paid | content_export_required | 已购买标记不是导出授权 |
| 抖音 preview_config.is_preview | content_preview_only | 不能作为完整视频交付 |
| 已知字段类型异常 | content_access_metadata_invalid | 权益信息无法确认，停止下载 |

抖音兼容上述字段的 camelCase 表达；分享视频、上游回退及图文入口使用同一检查。
B 站插件覆盖普通 BiliBiliIE 初始状态和格式提取，不复制整个上游提取器。充电标记在请求更多媒体信息前直接阻断，因此该路径不再进一步推断是否已购买、是否试看或是否 DRM。
字段缺失不等于证明免费：保留现有公开内容策略，不以本次规则宣称全平台付费识别覆盖。课程、番剧和未提供样本的“钻石”商品形态须单独验证。

所有新限制 inspection：access_decision=blocked、formats=[]、rights_basis=null、identity/protection=unknown；entitlement=restricted，字段异常时为 unknown。不伪造标题、原片时长或保护类型。content_export_required 是原因码，不是可运行的官方连接器，也不将 execution_mode 改为导入。
API 使用现有字符串原因及提示字段，无数据库迁移、生成 DTO 改动或新凭据接口。前端保留原布局，显示具体原因；任何非 downloadable 状态不渲染残留格式详情或下载按钮。

## 后续授权获取设计与立项门禁

只有拿到正式可验证的逐资产导出渠道后，再单独实现 OfficialConnector；公共解析插件不得自行升级为授权下载。
连接器需验证资产标识、授权主体、导出用途、有效期、允许范围和非 DRM 状态；授权只在服务端/用户设备受控范围使用，不进入日志、URL 参数或共享账号池。
取得资源后校验完整时长、音视频流、可解码性、首中尾样本和来源一致性，授权撤销及过期须在执行时复核。
未取得渠道时维持官方观看与自有文件上传；不以 Cookie、会员等级或 has_paid 自动放行。

投入建议（估算，不是承诺）：本期识别与回归数个工程日；有账号与合法样本后 B 站可行性验证约 3–5 工程日。生产连接器工作量取决于官方渠道与样本覆盖，不在本期排工期。抖音钻石需先明确商品入口和媒体形态。
